# Cognitive Cyber Threat Detection

A smart IoT-based system that combines environmental sensing, motion detection, and a web dashboard to detect and monitor potential cyber-physical threats in real time.

## Overview

This project implements a cognitive cyber threat detection system across a simulated IoT environment. Multiple ESP32 nodes collect real-time sensor data and network activity logs. Cyberattacks — including **DoS, spoofing, burst, and replay attacks** — were simulated using tools like Wireshark, Nmap, and hping3 on Kali Linux to generate labelled datasets for model training.

A **Flask backend** runs an anomaly detection model (scikit-learn) that continuously flags abnormal traffic patterns. All alerts and node statuses are displayed on a **real-time monitoring dashboard**.

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Venu-R/Cognitive-Cyber-threat-detection.git
cd Cognitive-Cyber-threat-detection
```

### 2. Install Python Dependencies

```bash
pip install flask scikit-learn pandas numpy
```

### 3. Flash the ESP32 Nodes

- Open the `.ino` file from `PIR_Motion_detector/` in the **Arduino IDE**
- Select your ESP32 board and the correct COM port
- Upload the sketch to each ESP32 node

### 4. Run the Weather Station Script

```bash
cd weather_station
python weather_monitor.py
```

### 5. Start the Flask Backend

```bash
cd "Web Dashboard"
python app.py
```

The anomaly detection model will load automatically and begin monitoring incoming sensor data from the ESP32 nodes.

### 6. View the Dashboard

Open your browser and go to:
http://127.0.0.1:5000
The dashboard displays live alerts, node statuses, and flagged anomalies across all connected nodes.

## ML Model

- **Type:** Anomaly Detection (scikit-learn)
- **Training Data:** Labelled CSV datasets generated by simulating DoS, spoofing, burst, and replay attacks
- **Function:** Flags abnormal network traffic and sensor behaviour in real time
